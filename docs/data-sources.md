# データソース

「日本人はいつ結婚し、別れてきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸は e-Stat API のメタ取得で確認済み。

## 1. 結論

**厚生労働省「人口動態調査」（政府統計コード `00450011`）が一次情報源。**
婚姻・離婚は確定数の上巻表を軸ごとに使い分ける（単一の「全軸入り」表はない）。

| ビュー | 見せる核 | 一次ソース（statsDataId） |
| --- | --- | --- |
| 時代 | 婚姻・離婚の件数/率、平均初婚年齢、再婚割合、平均同居期間 | `0003411561` / `0003411844` / `0003411837` / `0003411864` |
| 年齢・初再婚 | 年齢5歳階級 × 初婚/再婚 × 夫/妻 | `0003411840`（件数）/ `0003413965`（率） |
| 地域 | 都道府県の婚姻率・離婚率・平均初婚年齢 | `0003411835` / `0003411861` / `0003411845` |

出典表記: 厚生労働省「人口動態調査」（e-Stat）。

## 2. 採用データセット（メタ確認済み）

### `0003411561` — 上巻 年次別にみた人口動態総覧

- 軸: 人口動態総覧(27) × 時間軸(123: 1899–2024)
- 採用コード: `00270` 婚姻件数 / `00280` 離婚件数 / `00420` 婚姻率 / `00430` 離婚率
- 率の単位は**人口千対**（‰）
- fetch は `cdCat01` で上記4コードに絞る

### `0003411844` — 上巻 全婚姻－初婚別にみた年次別夫妻の平均婚姻年齢及び夫妻の年齢差

- 軸: 表章項目(1) × 平均婚姻年齢及び夫妻の年齢差(6) × 時間軸(123: 1899–2024)
- 採用: `00120` 初婚-夫 / `00130` 初婚-妻（全婚姻・年齢差は初期スコープ外）

### `0003411837` — 上巻 年次・夫－妻別にみた初婚－再婚別婚姻件数及び再婚の占める割合

- 軸: 表章項目(2: 件数/百分率) × 婚姻数・再婚の割合(7) × 時間軸(63: 1952–2024、一部5年刻み)
- 採用: 件数の初婚/再婚、百分率の `00150` 夫-再婚割合 / `00160` 妻-再婚割合

### `0003411864` — 上巻 年次別にみた同居期間別離婚件数及び百分率並びに平均同居期間

- 軸: 同居期間(31) × 時間軸(36: 1947–2024、近年は毎年・それ以前は5年刻み)
- 採用: `00400` 平均同居期間、百分率の `00260` 5年未満（短期離婚の目安）
- 細かい同居期間内訳の積み上げは初期スコープ外（時代ビューの指標に平均と5年未満割合のみ）

### `0003411840` — 上巻 年齢（5歳階級）×初婚－再婚×夫－妻×年次 婚姻件数

- 軸: 表章(1) × 年齢(16) × 夫・妻(2) × 初婚・再婚(2) × 時間軸(36)
- 「各届出年に結婚生活に入り届け出たもの」

### `0003413965` — 同上の婚姻率（人口千対）

- 年齢軸に総数・不詳なし（14階級）。件数表と突合して年齢ビューの率に使う

### `0003411835` / `0003411861` — 都道府県×年次の婚姻・離婚（件数・率）

- 地域(48: 全国+47県) × 時間軸(27: 1935–2024、近年毎年・それ以前は疎)
- 地図の主指標は率（人口千対）。相対値は県÷全国

### `0003411845` — 都道府県×年次の平均初婚年齢（夫・妻）

- 地域ビューの補完指標。届出年に結婚生活に入り届け出たもの

## 3. 除外・見送ったもの

| 候補 | 理由 |
| --- | --- |
| 職業大分類付きの婚姻・離婚表（年度次） | 年次が飛び、物語の主軸（時代・年齢・地域）から外れる |
| 中巻の各歳×都道府県クロス | セル数が大きく、初期3ビューに不要 |
| 国籍別・親権者別など | テーマ核（初再婚・率・同居・地域）の外側 |
| 社会・人口統計体系の婚姻指標 | 人口動態確定数の上巻で足りるため二重化しない |

## 4. 配信 cube

| ファイル | 次元 | 指標 |
| --- | --- | --- |
| `era.json` | metric × year | value（件数・‰・歳・年・割合） |
| `age.json` | age × sex × type × year | count / rate |
| `geo.json` | metric × year × area | value / relative |

## 5. 想定ビュー

- **時代** (`era`): 長期の婚姻・離婚、初婚年齢、再婚割合、同居期間
- **年齢** (`age`): 年齢階級 × 初婚/再婚 × 夫/妻
- **地域** (`geo`): 47都道府県の率・初婚年齢と全国比
